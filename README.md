Задача 1

Текст задачи

Дробная часть. Дана сигнатура функции: double fraction(double x);. Необходимо реализовать функцию таким образом, чтобы она возвращала только дробную часть числа x. Подсказка: вещественное число может быть преобразовано к целому путем отбрасывания дробной части.
Пример: x=3,67; Результат: 0,67

Алгоритм решения

1. Преобразовать вещественное число x к целому типу — дробная часть при этом отбрасывается. Полученное значение сохранить в переменной integer_part.
2. Вычислить разность x − integer_part. Это и есть дробная часть числа.
3. Вернуть полученный результат.

Тестирование
